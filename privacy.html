Privacy

Subscription data stays in your browser.

STACKCUT does not ask for bank credentials or connect to a bank. Subscription records you add or import are processed locally and encrypted in browser storage with a passphrase you choose.

Local records and imports

The app stores subscription names, prices, categories, transaction dates supplied by an import, your keep/cut decisions, and the number of audits you have run. It does not invent usage history, project counts, verification status, or renewal dates. CSV files are parsed by a local browser worker and are not uploaded by the app.

AES-GCM encryption with a passphrase-derived key protects saved data at rest from someone who only has a copy of browser storage. The app does not store the passphrase. This does not protect an unlocked browser from active scripts, malicious extensions, or device access. If you forget the passphrase, STACKCUT cannot recover the vault.

Exports

JSON exports are plaintext and contain the subscription information you chose to export. The file is not protected by the vault passphrase. Store or share it accordingly.

Pro access checks

The app requests /api/pro-status to check whether the server has verified an entitlement. If you enter an access code, it is sent to that endpoint for verification and is not saved by the app. A configured server allowlist or signed token can be checked; this build does not include a payment-provider webhook or automatic subscription lifecycle integration. A successful checkout alone does not automatically unlock app access.

Free plan limits

The static app applies free-plan limits in the browser. There is no authenticated server-side quota service in this build, so those limits are not a security or payment-enforcement boundary.

Older vaults

Older v2 data is migrated when it can be read. An older v3 encrypted vault can only be migrated if its session-only key is still available in that browser session. When it is not, the old stored data is left untouched and the app offers a separate new vault.

Hosting requests

Opening the site necessarily sends a request to its web host. Optional access checks also reach the site’s serverless endpoint. STACKCUT does not send subscription records to that endpoint.
